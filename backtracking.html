01. What is Backtracking?

Backtracking is an algorithm technique in which we build a solution step by step. If a choice does not work, we undo that choice and try another one.

  • Choose an option.
  • Explore the next step.
  • If it fails, undo the choice.
  • Try another possibility.

04. Python Code

def backtrack(nums, path):
    if len(path) == len(nums):
        print(path)
        return

    for i in range(len(nums)):
        if nums[i] not in path:
            path.append(nums[i])

            backtrack(nums, path)

            path.pop()

backtrack([1, 2, 3], [])

Remember: append() makes a choice and pop() undoes that choice.
