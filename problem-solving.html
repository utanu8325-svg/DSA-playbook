ROADMAP 03 / PRACTICE & OPTIMIZATION

Problem Solving

Learn how to approach coding problems, select the right algorithm and write efficient solutions.

1. How to Approach a Problem

  1. Understand: Read the problem and identify what is given and what is required.
  2. Check examples: Try small inputs and understand the expected output.
  3. Brute force: First think of a simple correct solution.
  4. Optimize: Look for repeated work or unnecessary operations.
  5. Analyze: Calculate time and space complexity.
  6. Test: Check normal cases, edge cases and large inputs.

Example: Find the Largest Element

arr = [12, 5, 30, 8, 17]

largest = arr[0]

for number in arr:
    if number > largest:
        largest = number

print("Largest:", largest)

Time: O(n) | Extra space: O(1)

2. Searching Algorithms

Linear Search

Linear Search checks each element one by one until the target is found or the list ends. It works on both sorted and unsorted lists.

arr = [4, 8, 2, 9, 5]
target = 9
found = False

for i in range(len(arr)):
    if arr[i] == target:
        print("Found at index", i)
        found = True
        break

if not found:
    print("Not Found")

Time: O(n) | Extra space: O(1)

Binary Search

Binary Search works on a sorted list. It repeatedly checks the middle element and removes half of the remaining search space.

arr = [2, 4, 6, 8, 10, 12]
target = 8
left = 0
right = len(arr) - 1

while left <= right:
    mid = (left + right) // 2

    if arr[mid] == target:
        print("Found at index", mid)
        break
    elif arr[mid] < target:
        left = mid + 1
    else:
        right = mid - 1

Time: O(log n) | Extra space: O(1) for this iterative version.

3. Sorting Algorithms

Bubble Sort

Repeatedly compares adjacent elements and swaps them if they are in the wrong order.

arr = [5, 2, 8, 1, 3]

for i in range(len(arr)):
    for j in range(0, len(arr) - i - 1):
        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]

print(arr)

Average/Worst time: O(n²) | Extra space: O(1)

Selection Sort

Finds the smallest element in the unsorted part and places it at the beginning.

arr = [64, 25, 12, 22, 11]

for i in range(len(arr)):
    minimum = i

    for j in range(i + 1, len(arr)):
        if arr[j] < arr[minimum]:
            minimum = j

    arr[i], arr[minimum] = arr[minimum], arr[i]

print(arr)

Time: O(n²) | Extra space: O(1)

Insertion Sort

Builds a sorted section by inserting each new element into its correct position.

arr = [5, 3, 4, 1, 2]

for i in range(1, len(arr)):
    key = arr[i]
    j = i - 1

    while j >= 0 and arr[j] > key:
        arr[j + 1] = arr[j]
        j = j - 1

    arr[j + 1] = key

print(arr)

Best time: O(n) | Average/Worst: O(n²) | Extra space: O(1)

Merge Sort

Divides the array into smaller halves, sorts them and merges the sorted halves. It uses recursion.

def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    result = []
    i = 0
    j = 0

    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            result.append(left[i])
            i = i + 1
        else:
            result.append(right[j])
            j = j + 1

    result.extend(left[i:])
    result.extend(right[j:])
    return result

numbers = [5, 2, 8, 1, 3]
print(merge_sort(numbers))

Time: O(n log n) | Extra space: O(n)

Quick Sort

Selects a pivot, places smaller elements on one side and larger elements on the other, then sorts the parts recursively.

def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    pivot = arr[-1]
    smaller = []
    larger = []

    for number in arr[:-1]:
        if number <= pivot:
            smaller.append(number)
        else:
            larger.append(number)

    return quick_sort(smaller) + [pivot] + quick_sort(larger)

numbers = [7, 2, 9, 1, 5]
print(quick_sort(numbers))

Average time: O(n log n) | Worst time: O(n²). This simple version uses extra lists and is not in-place.

4. Recursion

Recursion happens when a function calls itself to solve a smaller version of the same problem. Every recursive solution needs a base case to stop.

Factorial

def factorial(n):
    if n == 0 or n == 1:
        return 1

    return n * factorial(n - 1)

print(factorial(5))

Fibonacci

def fibonacci(n):
    if n <= 1:
        return n

    return fibonacci(n - 1) + fibonacci(n - 2)

for i in range(7):
    print(fibonacci(i))

The simple recursive Fibonacci solution takes O(2ⁿ) time. A more efficient approach uses memoization or iteration.

Backtracking Basics

Backtracking builds a possible solution step by step. If a choice does not lead to a valid solution, it goes back and tries another choice.

5. Important Problem-Solving Patterns

Two Pointers

Uses two positions to process an array or string, often moving from opposite ends.

arr = [1, 2, 3, 4, 6]
target = 6
left = 0
right = len(arr) - 1

while left < right:
    total = arr[left] + arr[right]

    if total == target:
        print(arr[left], arr[right])
        break
    elif total < target:
        left = left + 1
    else:
        right = right - 1

Sliding Window

Maintains a window over a sequence to solve problems involving continuous subarrays or substrings.

arr = [2, 1, 5, 1, 3, 2]
k = 3

window_sum = 0

for i in range(k):
    window_sum = window_sum + arr[i]

maximum = window_sum

for i in range(k, len(arr)):
    window_sum = window_sum + arr[i] - arr[i - k]

    if window_sum > maximum:
        maximum = window_sum

print(maximum)

Fast and Slow Pointers

Uses two pointers moving at different speeds. It is commonly used to detect cycles in linked lists.

slow = head
fast = head

while fast is not None and fast.next is not None:
    slow = slow.next
    fast = fast.next.next

    if slow == fast:
        print("Cycle detected")
        break

Prefix Sum

Stores cumulative sums so range-sum queries can be answered efficiently.

arr = [2, 4, 6, 8]
prefix = [0]

for number in arr:
    prefix.append(prefix[-1] + number)

left = 1
right = 3

answer = prefix[right + 1] - prefix[left]
print(answer)

For a range from index left to right, the sum is prefix[right + 1] - prefix[left].
