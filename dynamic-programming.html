Dynamic Programming

Solve complex problems by breaking them into smaller overlapping subproblems and storing their answers.

01. What is Dynamic Programming?

Dynamic Programming (DP) is an algorithm technique that avoids solving the same subproblem again and again by storing previously calculated results.

  • Break a problem into smaller subproblems.
  • Store answers to repeated subproblems.
  • Reuse stored answers to save time.

02. Fibonacci Example

Fibonacci numbers are calculated by adding the previous two numbers.

Formula: F(n) = F(n - 1) + F(n - 2)

Sequence: 0, 1, 1, 2, 3, 5, 8, 13, 21...

04. Python Code

dp = [0] * 7

dp[0] = 0
dp[1] = 1

for i in range(2, 7):
    dp[i] = dp[i - 1] + dp[i - 2]

print(dp)

Here, the list dp stores the answers so we do not calculate them repeatedly.
