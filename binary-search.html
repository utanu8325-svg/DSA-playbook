Binary Search

Learn how to search efficiently in a sorted array by repeatedly dividing the search space into half.

Beginner Friendly Arrays & Searching 15 Min Read

01. What is Binary Search?

Binary Search is an efficient searching technique used on sorted arrays. It checks the middle element and eliminates half of the search space in every step.

Time Complexity: O(log n)

Space Complexity: O(1)

02. Understand the Example

Find the target number 7 in this sorted array.

1 3 5 7 9 11

Middle element = 5

7 is greater than 5, so search the right half.

Middle element = 7

Answer = 7

04. Python Code

arr = [1, 3, 5, 7, 9, 11]

target = 7

left = 0
right = len(arr) - 1

while left <= right:

    mid = (left + right) // 2

    if arr[mid] == target:
        print("Found at index", mid)
        break

    elif arr[mid] < target:
        left = mid + 1

    else:
        right = mid - 1
