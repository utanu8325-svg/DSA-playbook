ROADMAP 02 / CORE CONCEPTS

Data Structures

Learn how data is organized, stored and accessed efficiently in computer programs.

1. Arrays

An array stores multiple elements in an ordered sequence. Python uses lists as its flexible built-in array-like structure. Indexing starts from 0.

Access and Traversal

arr = [10, 20, 30, 40]

print(arr[0])

for item in arr:
    print(item)

Insertion and Deletion

arr = [10, 20, 30]

arr.append(40)
arr.insert(1, 15)
print(arr)

arr.remove(20)
print(arr)

Searching

arr = [5, 10, 15, 20]
target = 15

for i in range(len(arr)):
    if arr[i] == target:
        print("Found at index", i)
        break

Typical list costs: indexing O(1), searching O(n), appending O(1) amortized, inserting/deleting near the beginning O(n).

2. Strings

A string is a sequence of characters. Strings in Python are immutable, which means their characters cannot be changed directly.

Traversal

text = "PYTHON"

for char in text:
    print(char)

Reverse a String

text = "hello"
reversed_text = text[::-1]
print(reversed_text)

Palindrome Check

A palindrome reads the same forward and backward.

text = "madam"

if text == text[::-1]:
    print("Palindrome")
else:
    print("Not Palindrome")

Count Characters

text = "banana"
count = 0

for char in text:
    if char == "a":
        count = count + 1

print(count)

String traversal takes O(n). Creating a reversed string also takes O(n) time and additional space.

3. Linked Lists

A linked list is a sequence of nodes. Each node stores data and a reference to the next node. Unlike arrays, linked-list nodes do not need to be stored next to each other in memory.

Singly Linked List

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

first = Node(10)
second = Node(20)
third = Node(30)

first.next = second
second.next = third

current = first

while current is not None:
    print(current.data)
    current = current.next

Types of Linked Lists

  • Singly Linked List: Each node points to the next node.
  • Doubly Linked List: Each node points to both previous and next nodes.
  • Circular Linked List: The last node connects back to the first node.

Accessing an element by position takes O(n). Inserting at the head takes O(1).

4. Stacks

A stack follows LIFO: Last In, First Out. The last element added is the first one removed.

Common operations: push (add), pop (remove), peek (view top).

stack = []

stack.append(10)
stack.append(20)
stack.append(30)

print("Top:", stack[-1])

removed = stack.pop()
print("Removed:", removed)
print("Stack:", stack)

Applications include undo operations, browser history, function calls and expression evaluation.

Push and pop at the end of a Python list are O(1) amortized.

5. Queues

A queue follows FIFO: First In, First Out. The first element added is the first one removed.

Common operations: enqueue (add), dequeue (remove), front (view first).

from collections import deque

queue = deque()

queue.append(10)
queue.append(20)
queue.append(30)

print("Front:", queue[0])

removed = queue.popleft()
print("Removed:", removed)
print("Queue:", queue)

Applications include task scheduling, printer queues and Breadth First Search (BFS).

Appending and removing from the front using deque are O(1).

6. Hashing

Hashing uses a hash function to map a key to a location. Python dictionaries and sets use hash tables internally.

Dictionary

student = {
    "name": "Aman",
    "age": 20,
    "course": "AIML"
}

print(student["name"])
student["age"] = 21
print(student)

Set

A set stores unique elements and removes duplicates.

numbers = [1, 2, 2, 3, 3, 4]
unique_numbers = set(numbers)

print(unique_numbers)

Frequency Counting

arr = [1, 2, 2, 3, 1, 2]
frequency = {}

for number in arr:
    if number in frequency:
        frequency[number] = frequency[number] + 1
    else:
        frequency[number] = 1

print(frequency)

Dictionary and set lookup are O(1) on average, but can be O(n) in the worst case.
