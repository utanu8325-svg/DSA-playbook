Advanced DSA

Explore trees, graphs, greedy algorithms and dynamic programming to solve complex problems efficiently.

1. Trees

A tree is a non-linear data structure made of nodes connected by edges. It has a root node and child nodes. A tree with n nodes has n - 1 edges.

Important Terminology

  • Root: The topmost node.
  • Parent: A node that has children.
  • Child: A node connected below a parent.
  • Leaf: A node with no children.
  • Height: The longest downward path from a node to a leaf, measured in edges.
  • Depth: The number of edges from the root to a node.

Binary Tree

A binary tree is a tree in which each node has at most two children: left and right.

class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

root = Node(10)
root.left = Node(20)
root.right = Node(30)

print(root.data)
print(root.left.data)
print(root.right.data)

Tree Traversals

Traversal means visiting every node in a particular order.

  • Inorder: Left, Root, Right.
  • Preorder: Root, Left, Right.
  • Postorder: Left, Right, Root.
def inorder(root):
    if root is not None:
        inorder(root.left)
        print(root.data)
        inorder(root.right)

def preorder(root):
    if root is not None:
        print(root.data)
        preorder(root.left)
        preorder(root.right)

def postorder(root):
    if root is not None:
        postorder(root.left)
        postorder(root.right)
        print(root.data)

Tree traversal takes O(n) time because each node is visited once. Recursive space is O(h), where h is tree height.

Binary Search Tree (BST)

A BST is a binary tree where values smaller than a node are placed in its left subtree and values greater than a node are placed in its right subtree.

Search, insertion and deletion take O(log n) on average in a balanced BST, but O(n) in the worst case when the tree becomes skewed.

2. Graphs

A graph consists of vertices (nodes) and edges (connections). Graphs can be directed or undirected, weighted or unweighted.

Graph Representation

An adjacency list stores each vertex with a list of its neighboring vertices.

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C"]
}

print(graph["A"])

Breadth First Search (BFS)

BFS visits nodes level by level. It uses a queue and is useful for finding the shortest path in an unweighted graph.

from collections import deque

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C"]
}

visited = set()
queue = deque(["A"])
visited.add("A")

while queue:
    node = queue.popleft()
    print(node)

    for neighbour in graph[node]:
        if neighbour not in visited:
            visited.add(neighbour)
            queue.append(neighbour)

Depth First Search (DFS)

DFS explores one path as deeply as possible before going back. It can be implemented using recursion or a stack.

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C"]
}

visited = set()

def dfs(node):
    visited.add(node)
    print(node)

    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(neighbour)

dfs("A")

BFS and DFS take O(V + E) time using an adjacency list, where V is vertices and E is edges.

Shortest Path Basics

  • BFS finds shortest paths in unweighted graphs.
  • Dijkstra's algorithm finds shortest paths when edge weights are non-negative.
  • Bellman-Ford can handle negative edge weights and detect reachable negative cycles.

3. Greedy Algorithms

A greedy algorithm makes the best-looking choice at each step, hoping to reach an overall optimal solution. It works only when the problem has the right greedy properties.

Activity Selection

Choose the maximum number of non-overlapping activities by sorting them by finishing time and selecting each activity that starts after the last selected activity ends.

activities = [
    (1, 3),
    (2, 4),
    (3, 5),
    (6, 7),
    (5, 9)
]

activities.sort(key=lambda item: item[1])

selected = []
last_end = -1

for activity in activities:
    start = activity[0]
    end = activity[1]

    if start >= last_end:
        selected.append(activity)
        last_end = end

print(selected)

Time: O(n log n) because of sorting. The selection scan takes O(n).

Other Greedy Problems

  • Fractional Knapsack.
  • Activity Selection.
  • Job Sequencing with Deadlines.
  • Minimum number of coins for suitable coin systems.
  • Interval scheduling and merging.

Important: Greedy does not always give the optimal answer. For example, the general 0/1 Knapsack problem needs a different approach such as Dynamic Programming.

4. Dynamic Programming (DP)

Dynamic Programming solves problems by breaking them into overlapping subproblems and storing their answers so the same work is not repeated.

Two Main Approaches

  • Memoization: Top-down approach. Solve recursively and store results.
  • Tabulation: Bottom-up approach. Build answers iteratively in a table.

Fibonacci using Memoization

def fibonacci(n, dp):
    if n <= 1:
        return n

    if dp[n] != -1:
        return dp[n]

    dp[n] = fibonacci(n - 1, dp) + fibonacci(n - 2, dp)
    return dp[n]

n = 6
dp = [-1] * (n + 1)

print(fibonacci(n, dp))

Time: O(n) | Space: O(n) for the DP array and recursion stack.

Fibonacci using Tabulation

n = 6
dp = [0] * (n + 1)

if n >= 1:
    dp[1] = 1

for i in range(2, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]

print(dp[n])

Time: O(n) | Space: O(n).

0/1 Knapsack

Given items with weights and values, choose items to maximize total value without exceeding the capacity. Each item can be selected at most once.

weights = [1, 3, 4, 5]
values = [1, 4, 5, 7]
capacity = 7
n = len(weights)

dp = [[0] * (capacity + 1) for i in range(n + 1)]

for i in range(1, n + 1):
    for w in range(capacity + 1):
        dp[i][w] = dp[i - 1][w]

        if weights[i - 1] <= w:
            value = values[i - 1] + dp[i - 1][w - weights[i - 1]]

            if value > dp[i][w]:
                dp[i][w] = value

print("Maximum value:", dp[n][capacity])

Time: O(n × capacity) | Space: O(n × capacity).

Longest Common Subsequence (LCS)

LCS finds the longest sequence that appears in two strings in the same relative order, not necessarily continuously.

a = "abcde"
b = "ace"
n = len(a)
m = len(b)

dp = [[0] * (m + 1) for i in range(n + 1)]

for i in range(1, n + 1):
    for j in range(1, m + 1):
        if a[i - 1] == b[j - 1]:
            dp[i][j] = 1 + dp[i - 1][j - 1]
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

print("LCS length:", dp[n][m])

Time: O(n × m) | Space: O(n × m).

How to Identify a DP Problem

  • The problem can be divided into smaller states.
  • The same subproblems appear repeatedly.
  • The answer can be built from answers to smaller subproblems.
  • You need to find an optimal value or count possible ways.

  • Understand basic tree terminology and traversals.

  • Understand when a greedy approach works.

  • Analyze time and space complexity for every solution.
