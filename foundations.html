DSA Foundations

Build a strong programming foundation before solving Data Structures and Algorithms problems.

1. Programming Basics

Programming means giving instructions to a computer to perform a task. Python is a beginner-friendly language used to implement DSA concepts.

Variables and Data Types

A variable stores a value. Common Python data types include integers, floats, strings and booleans.

name = "Urvashi"
age = 19
height = 5.3
is_student = True

print(name)
print(age)
print(height)
print(is_student)

Input and Output

input() takes information from the user. print() displays the result.

name = input("Enter your name: ")
print("Hello", name)

Conditional Statements

Conditions allow a program to make decisions using if, elif and else.

number = 7

if number > 0:
    print("Positive")
elif number < 0:
    print("Negative")
else:
    print("Zero")

Loops

Loops repeat a block of code. A for loop is commonly used when the number of repetitions is known.

for i in range(1, 6):
    print(i)

Functions

A function is a reusable block of code that performs a particular task.

def greet():
    print("Welcome to DSA")

greet()

2. Time Complexity

Time complexity describes how the running time of an algorithm grows as the input size increases. It is commonly expressed using Big O notation.

O(1) — Constant Time

The operation takes roughly the same time regardless of input size.

arr = [10, 20, 30, 40]
print(arr[0])

O(n) — Linear Time

The number of operations grows with the input size.

arr = [10, 20, 30, 40]

for item in arr:
    print(item)

O(n²) — Quadratic Time

A common example is a loop inside another loop.

for i in range(3):
    for j in range(3):
        print(i, j)

O(log n) — Logarithmic Time

The search space is repeatedly divided into smaller parts. Binary Search is a common example.

arr = [2, 4, 6, 8, 10, 12]
target = 10
left = 0
right = len(arr) - 1

while left <= right:
    mid = (left + right) // 2

    if arr[mid] == target:
        print("Found")
        break
    elif arr[mid] < target:
        left = mid + 1
    else:
        right = mid - 1

Common growth order: O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ).

3. Space Complexity

Space complexity measures how much additional memory an algorithm needs as input size grows.

Constant Extra Space — O(1)

number = 10
square = number * number
print(square)

Linear Extra Space — O(n)

arr = [1, 2, 3, 4]
copy_arr = []

for item in arr:
    copy_arr.append(item)

print(copy_arr)

Auxiliary space means the extra memory used by an algorithm, excluding the input itself.

4. Basic Mathematics for DSA

Even or Odd

number = 8

if number % 2 == 0:
    print("Even")
else:
    print("Odd")

Prime Number

A prime number is greater than 1 and has exactly two positive factors: 1 and itself.

number = 13
is_prime = True

if number <= 1:
    is_prime = False
else:
    for i in range(2, number):
        if number % i == 0:
            is_prime = False
            break

if is_prime:
    print("Prime")
else:
    print("Not Prime")

GCD (Greatest Common Divisor)

GCD is the largest number that divides two numbers exactly.

a = 12
b = 18

while b != 0:
    remainder = a % b
    a = b
    b = remainder

print("GCD:", a)

LCM (Least Common Multiple)

a = 12
b = 18
x = a
y = b

while y != 0:
    remainder = x % y
    x = y
    y = remainder

gcd = x
lcm = (a * b) // gcd
print("LCM:", lcm)
